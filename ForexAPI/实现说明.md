# Forex.com API 接口实现说明

## 项目结构

```
ForexAPI/
├── ForexComAPI.h          # API 客户端头文件
├── ForexComAPI.cpp        # API 客户端实现
├── HttpClient.h           # HTTP 客户端接口
├── HttpClient.cpp         # HTTP 客户端实现（WinHTTP/CURL）
├── README.md              # 使用文档
├── forex_api_config.example.json  # 配置文件示例
└── 实现说明.md            # 本文档
```

## 已实现功能

### 1. ✅ API 客户端框架
- `ForexComAPIClient` 类：主要的 API 客户端
- `APIConfig` 结构：API 配置参数
- 初始化和连接管理

### 2. ✅ HTTP 客户端
- Windows 平台：使用 WinHTTP
- Linux/Mac 平台：使用 CURL（需要安装 libcurl）
- 支持 GET、POST、DELETE 等方法
- 支持 HTTPS
- 超时控制

### 3. ✅ 报价获取接口
- `GetQuote()`: 获取单个品种报价
- `GetQuotes()`: 批量获取报价
- 返回 `Quote` 结构（bid, ask, timestamp）

### 4. ✅ 交易指令接口
- `PlaceOrder()`: 下达订单
- `CancelOrder()`: 取消订单
- `GetOrderStatus()`: 查询订单状态
- 支持市价单、限价单、止损单
- 支持止损和止盈设置

### 5. ✅ 账户管理接口
- `GetAccountInfo()`: 获取账户信息
- `GetOpenPositions()`: 获取所有持仓
- `GetPosition()`: 获取单个持仓
- `ClosePosition()`: 平仓
- `CloseAllPositions()`: 平掉所有持仓

## 编译说明

### Windows (Visual Studio)

1. **创建项目**：
   - 创建新的 C++ 项目（Win32 控制台应用程序或 DLL）
   - 添加所有 `.cpp` 和 `.h` 文件

2. **配置项目**：
   - C++ 标准：C++11 或更高
   - 字符集：使用多字节字符集或 Unicode

3. **链接库**：
   - WinHTTP: 已包含在 Windows SDK 中，无需额外链接
   - 如果使用 JSON 库，需要链接相应的库文件

4. **编译**：
   ```bash
   # 在 Visual Studio 中直接编译
   # 或使用命令行：
   cl /EHsc ForexComAPI.cpp HttpClient.cpp /link
   ```

### Linux/Mac (CMake)

1. **安装依赖**：
   ```bash
   # Ubuntu/Debian
   sudo apt-get install libcurl4-openssl-dev
   
   # macOS
   brew install curl
   ```

2. **创建 CMakeLists.txt**：
   ```cmake
   cmake_minimum_required(VERSION 3.10)
   project(ForexComAPI)
   
   set(CMAKE_CXX_STANDARD 11)
   
   # 查找 CURL
   find_package(CURL REQUIRED)
   
   # 添加源文件
   add_library(forexapi STATIC
       ForexComAPI.cpp
       HttpClient.cpp
   )
   
   # 链接库
   target_link_libraries(forexapi ${CURL_LIBRARIES})
   target_include_directories(forexapi PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})
   ```

3. **编译**：
   ```bash
   mkdir build
   cd build
   cmake ..
   make
   ```

## 使用示例

### 基本使用

```cpp
#include "ForexComAPI.h"
#include <iostream>

using namespace ForexComAPI;

int main() {
    // 配置 API
    APIConfig config;
    config.apiKey = "your_api_key";
    config.apiSecret = "your_api_secret";
    config.baseUrl = "https://api.forex.com/v1";
    config.useSandbox = false;
    config.timeoutMs = 5000;
    
    // 创建客户端
    ForexComAPIClient client(config);
    
    // 初始化
    if (!client.Initialize()) {
        std::cerr << "初始化失败: " << client.GetLastError() << std::endl;
        return -1;
    }
    
    // 获取报价
    Quote quote;
    if (client.GetQuote("EURUSD", quote)) {
        std::cout << "EURUSD: Bid=" << quote.bid 
                  << ", Ask=" << quote.ask << std::endl;
    } else {
        std::cerr << "获取报价失败: " << client.GetLastError() << std::endl;
    }
    
    // 下达订单
    OrderRequest orderReq;
    orderReq.symbol = "EURUSD";
    orderReq.side = OrderSide::BUY;
    orderReq.quantity = 1.0;
    orderReq.type = OrderType::MARKET;
    
    OrderResponse orderResp;
    if (client.PlaceOrder(orderReq, orderResp)) {
        std::cout << "订单已下达: " << orderResp.orderId << std::endl;
    } else {
        std::cerr << "下单失败: " << client.GetLastError() << std::endl;
    }
    
    return 0;
}
```

### 集成到现有 EA

1. **在 EA 中调用 API**：
   - 创建 `ForexComAPIClient` 实例
   - 在 `OnInit()` 中初始化
   - 在 `OnTick()` 中获取报价和下达订单

2. **替换 MT4 报价获取**：
   ```cpp

   double ask = MarketInfo("EURUSD", MODE_ASK);
   
   // 改为：

   if (apiClient.GetQuote("EURUSD", quote)) {
       double bid = quote.bid;
       double ask = quote.ask;
   }
   ```

   ```cpp
   req.quantity = 1.0;
   req.type = OrderType::MARKET;
   
   OrderResponse resp;

       // 订单成功
   }
   ```

## 注意事项

1. **API 密钥安全**：
   - 不要将 API Key 和 Secret 提交到版本控制系统
   - 使用配置文件或环境变量存储
   - 在生产环境中使用加密存储

2. **API 限制**：
   - 注意 Forex.com 的 API 调用频率限制
   - 实现请求限流和重试机制

3. **网络延迟**：
   - 使用低延迟网络连接
   - 考虑在同一数据中心部署
   - 使用 WebSocket 减少延迟

4. **错误处理**：
   - 所有 API 调用都应检查返回值
   - 实现适当的错误日志记录
   - 处理网络超时和重连
